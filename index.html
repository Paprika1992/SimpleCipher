Секретный ключ

Зачем нужен секретный ключ?

Секретный ключ - это твоя персональная "приправа" для алгоритма. Шифр, полученный с использованием такого ключа получится расшифровать только передав этот же ключ при расшифровке.
Эта мера гарантирует, что даже если злоумышленник заполучит твои шифры, без секретного ключа у него не получится расшифровать их!

Обязательно сохрани этот ключ. Каждое значение, зашифрованное с помощью секретного ключа может быть расшифрована только с помощью него же!
